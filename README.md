## The entry

> The self-checkout screamed "UNEXPECTED ITEM IN THE BAGGING AREA" at one banana. One banana! It has scanned a thousand bananas, it knows what a banana is — but today it chose violence, called a human, and made me wait while a teenager pressed a button like a priest absolving my groceries.

A short, funny rant about a small everyday annoyance — one banana versus
a machine that has seen a thousand bananas and still chose violence.
